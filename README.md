# Aura Soft

موقع عربي RTL لشركة تقنية تُحوّل الأفكار إلى حلول رقمية واضحة. يتضمن الموقع العام، هوية Aura البصرية، استقبال طلبات المشاريع، رسائل التواصل، دراسات الحالة، المراجعات المعتمدة، ولوحة إدارة محمية قابلة للتوسع.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

يتطلب تشغيل مسارات البيانات وجود `DATABASE_URL` أو `POSTGRES_URL` لقاعدة PostgreSQL. عند غياب الاتصال، تستمر الواجهة العامة في عرض حالات fallback، لكن العمليات التي تحتاج قاعدة البيانات لن تُحفظ.

## التحقق قبل الدمج

```bash
pnpm check
pnpm lint
pnpm test
pnpm build
```

أمر `build` يبني تطبيق Next.js فقط. لا يتم تعديل قاعدة البيانات أثناء البناء.

## قاعدة البيانات وDrizzle

بعد تعديل `drizzle/schema.ts`، ولّد migration جديدة ثم طبّقها على بيئة قاعدة البيانات:

```bash
DATABASE_URL="postgresql://..." pnpm db:generate
DATABASE_URL="postgresql://..." pnpm db:migrate
```

يجب تشغيل migrations كخطوة نشر مستقلة ومراجعتها قبل تطبيقها على الإنتاج. تم عزل migration القديمة المبنية على MySQL داخل `drizzle/legacy/` لأن المخطط الحالي مبني على PostgreSQL.

## مسارات الموقع

| المسار | الوظيفة |
| --- | --- |
| `/` | الصفحة الرئيسية وعناصر الثقة والأعمال والمراجعات المعتمدة عند توفرها |
| `/work` | قائمة الأعمال المنشورة أو الحالة الفارغة الصادقة |
| `/work/[slug]` | تفاصيل دراسة الحالة والنتائج والتقنيات |
| `/contact` | بيانات التواصل ونموذج الرسائل |
| `/request` | طلب مشروع مع رقم مرجع بعد الإرسال |
| `/admin` | مركز العمليات والطلبات والحالات والأولويات |
| `/admin/portfolio` | إنشاء مسودات الأعمال ونشرها وأرشفتها |
| `/admin/testimonials` | اعتماد المراجعات أو رفضها أو أرشفتها |
| `/admin/messages` | متابعة رسائل التواصل وإغلاقها |
| `/admin/content` | إدارة مفاتيح المحتوى العامة |

## بيانات الإدارة

تُتاح صفحات الإدارة للحساب الذي يحمل دور `admin` فقط، وتتحقق إجراءات الإدارة من الصلاحية في الخادم عبر `adminProcedure`. الحساب الإداري الحالي يعتمد إعدادات البيئة الموجودة في طبقة المصادقة، ولا يجب رفع كلمات المرور أو الأسرار إلى المستودع.

## نموذج البيانات

يستخدم المشروع الجداول التالية:

| الجدول | الغرض |
| --- | --- |
| `users` | المستخدمون والأدوار |
| `project_requests` | طلبات المشاريع مع المرجع والحالة والأولوية والمتابعة |
| `company_settings` | بيانات الشركة والتواصل والسياسات |
| `portfolio_items` | الأعمال ودراسات الحالة وحالات النشر |
| `testimonials` | المراجعات مع موافقة النشر والحالة |
| `contact_messages` | رسائل التواصل وحالات المعالجة |
| `audit_logs` | سجل الإجراءات الإدارية |
| `site_content` | المحتوى العام القابل للتحرير |

## الهوية والأصول

يستخدم الرأس والتذييل الشعار الجديد من `public/brand/aura-logo-mark.png`. توجد نسخة أفقية في `public/brand/aura-logo-horizontal.png` للاستخدام في المساحات البصرية الواسعة. يستحسن نقل الأصول إلى تخزين المشروع المخصص عند توفر بيئة WebDev إنتاجية، بدل الاعتماد على ملفات محلية في deployments التي تفرض تخزينًا خارجيًا.

## الاختبارات والجودة

يحتوي المشروع على اختبارات تحقق لمدخلات طلب المشروع ورصد حقل honeypot الخاص بالرسائل المزعجة. يجب إضافة اختبارات تكامل لمسارات قاعدة البيانات والصلاحيات والموافقات قبل إطلاق النسخة الإنتاجية النهائية.

## التحليلات والخصوصية

يظهر للزائر خيار واضح قبل تحميل أداة القياس. عند الموافقة فقط، تُسجل أحداث CTA الأساسية وإرسال نموذج المشروع باستخدام موفر التحليلات المدمج عند توافره. يجب استكمال صفحات سياسة الخصوصية وشروط الاستخدام ببيانات الشركة الفعلية قبل النشر.
